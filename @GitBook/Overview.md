# Visão Geral

Este GitBook apresenta a linguagem **Português Puro**, uma linguagem de programação em português brasileiro (pt‑BR) que permite escrever código usando palavras e estruturas da língua natural.

A linguagem está organizada em vários diretórios:

- **Regras/** – documentação de semântica e da gramática da linguagem.
- **Gramática/** – pacote npm que contém a gramática Langium (`pop.langium`) e ferramentas para gerar o parser.
- **Código-Fonte/** – implementação real do compilador em 16 estágios escritos em `.pop`.
- **Algoritmos/** – exemplos de programas completos (Agenda Telefônica, Basteróides, Janela, Sudoku).
- **Mensagens de Erro/** – guia de mensagens emitidas pelo compilador.
- **Documentação/** e **Índices/** – documentação adicional e índices de referência.

A seguir, cada seção detalha como configurar, usar e contribuir para o projeto.
